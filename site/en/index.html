What it does

🧭

Browser only

Websites go through the VPN, not the whole computer: games, torrents and work apps don't use your subscription traffic.

🎯

Per-site rules

Your own “always via VPN” and “always direct” lists, and a dedicated server for a site — say, ChatGPT via the US.

🏦

Ready for Russia

Russian banks and services open directly; ~1200 sites blocked in Russia go via VPN, and the list updates itself.

⚡

Auto server

Picks the fastest working server and switches when the current one goes down or gets blocked.

🔒

No leaks

If the core crashes, VPN sites don't open instead of leaking your real IP. WebRTC leaks are blocked too.

📊

Traffic and expiry

See used traffic and the expiry date; get notified 3 days before it ends and at 90% traffic.

🚀

Speed test

Mbit/s for any server without switching to it. Plus ping, sorting and search by country.

🔄

One-click updates

New versions install with the “Update” button right in the window. English and Russian interface.

Install — 5 minutes

  1. Install the core with one command

    Windows: press Win + X → “Terminal”, paste the command and press Enter. The installer talks in Russian — when you see the green «Готово» (“Done”), it's finished. No admin rights needed.

    irm https://raw.githubusercontent.com/DUFUSxD/lazeyka/main/install.ps1 | iex

    macOS and Linux: open a terminal (on a Mac — Cmd + Space → “Terminal”) and run:

    curl -fsSL https://raw.githubusercontent.com/DUFUSxD/lazeyka/main/install.sh | sh

    Linux says “curl: command not found”? First run sudo apt install curl (Ubuntu, Debian, Mint), sudo dnf install curl (Fedora) or sudo pacman -S curl (Arch), then repeat the command.

  2. Add the extension to your browser

    On the extensions page turn on “Developer mode”, click “Load unpacked” and pick %LOCALAPPDATA%\Lazeyka\extension (on macOS and Linux — ~/Lazeyka/extension).

  3. Paste the secret and your subscription

    The secret is already in your clipboard after install. Paste it and your subscription link in settings, click “Save”, then the big button.

FAQ

Can I use a VLESS / Reality subscription right in the browser?

Yes. Browsers can't speak VLESS — extensions only get HTTP and SOCKS proxies — so a small mihomo core runs next to the browser and Lazeyka controls it. One command to install, everything else in the extension window.

Why not just use v2rayN, Hiddify or Happ on my PC?

With Lazeyka only the browser goes through the VPN: games, torrents, system updates and work apps stay direct and don't eat your subscription traffic, and you can pick a server per site.

Will my Remnawave / 3x-ui / Marzban / Telegram-bot subscription work?

Yes — any https:// subscription link in Clash/mihomo (YAML) format or as a base64 list of keys. With a device limit, Lazeyka counts as a separate device, like a phone.

Is it free?

Yes, Lazeyka is free and open source (MIT). You only pay for your subscription to whoever provides it.

Where do my subscriptions go?

Nowhere: they stay in your browser and in the core on your computer. Lazeyka has no servers, accounts or telemetry.

Is there a Mac, Linux or mobile version?

macOS and Linux — yes, see the install command above. You need a Chromium browser: Chrome, Edge, Brave, Yandex Browser. On phones extensions can't control the proxy — use apps on the same mihomo core there, such as FlClash.

Do I need admin rights?

No. Everything is installed for your user only, and the core only accepts connections from the same computer.
