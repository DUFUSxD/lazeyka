# Что нового

Пункты отсюда показываются в окне «Лазейки», когда выходит новая версия.

## 1.8.1
- Кнопки показывают, что работа идёт: на «Пинг», «Обновить», «Сохранить» и тесте скорости крутится кружок, у кнопки обновления подписок — стрелка

## 1.8.0
- Лазейка работает на macOS и Linux: ядро ставится одной командой в терминале и запускается само при входе в систему
- Ни на одной системе не нужны права администратора
- Подсказки и команды в окне — для твоей системы: «Терминал» на Mac, терминал на Linux, Win+R на Windows
- Установка больше не падает, если GitHub ограничил число запросов: версия ядра узнаётся без его API
- Панель подписки видит настоящую систему устройства (Windows, macOS или Linux)

## 1.7.1
- Исправлены ошибки в списке серверов, уведомлениях и при зависании ядра
- После «Скрыто неработающих — показать» галочка «Скрывать неработающие» переставала действовать до закрытия окна. Теперь скрытые снова прячутся при новом поиске или переходе в настройки
- Исправлено: если серверов становилось меньше десяти, спрятанное поле поиска продолжало фильтровать список
- Исправлено: открытый список «Сервер для сайта» сбрасывался, пока ⚡ Авто подбирал сервер
- Исправлено: «⚡ Авто подбирает сервер…» мог перестать обновляться, уведомления иногда приходили дважды, свёрнутая подписка разворачивалась после смены адреса провайдером

## 1.7.0
- Если ядро не запущено, Лазейка сразу говорит об этом и показывает команду — ещё до настройки
- «Запустить ядро» на компьютере без ядра копирует команду установки
- Подготовка к магазинам расширений: версия из Chrome Web Store / Edge Add-ons обновляется магазином
- К каждому релизу прикладывается архив расширения

## 1.6.1
- Пока логотип подписки загружается, на его месте кружок с буквой, а не пустое место
- У проекта появились сайт, README на английском и лицензия MIT

## 1.6.0
- Английский интерфейс: ⚙ → «Язык · Language» (по умолчанию — как у браузера; у тех, кто обновился, остаётся русский)
- Поиск серверов понимает страны: «Британия», «UK», «Англия», «Лондон» найдут и «🇬🇧 London», и «United Kingdom»

## 1.5.0
- Серверы подписки можно свернуть и развернуть — щелчком по её шапке; Лазейка это запомнит

## 1.4.1
- Логотип подписки берётся и с сайта личного кабинета провайдера — если у адреса подписки своего значка нет

## 1.4.0
- Подписки с лимитом устройств (Remnawave и др.) больше не отвечают «не найдено»: Лазейка представляется отдельным устройством
- Название, ссылки «Поддержка» и «Кабинет» и сообщения от провайдера — после кнопки «Разрешить» в настройках
- Уведомления: подписка заканчивается через 3 дня, уже закончилась или израсходовано 90% трафика
- Скорость и трафик через VPN прямо под кнопкой питания
- Тест скорости любого сервера, не переключаясь на него
- Серверы можно сортировать по пингу или названию и прятать неработающие
- Провайдер сменил адрес подписки — Лазейка переходит на новый сама

## 1.3.1

- Подписка, которая не скачалась, видна в списке — с понятной причиной и кнопкой «Скачать через VPN»
- Ошибки скачивания подписок без технических подробностей и без личного токена из ссылки
- «Качать подписки через VPN» работает через ⚡ Авто — даже если выбранный сервер не отвечает
