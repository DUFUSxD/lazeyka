# Лазейка

VPN только для браузера, через **твои** серверы. Вставляешь ссылку на подписку (3x-ui, Marzban, Remnawave, любой провайдер), выбираешь сервер, жмёшь «ВКЛ», как в Browsec. Можно указать, какие сайты идут через VPN, а какие напрямую.

Работает в Chrome, Edge, Яндекс.Браузере и любом другом Chromium. Поддерживаются VLESS (в том числе Reality), VMess, Trojan, Shadowsocks, Hysteria2, TUIC и всё остальное, что умеет [mihomo](https://github.com/MetaCubeX/mihomo).

## Возможности

- **Свои подписки.** Можно вставить несколько ссылок. Серверы скачиваются автоматически и обновляются раз в час.
- **⚡ Авто.** Выбирает самый быстрый живой сервер и сам переключается, если текущий заблокировали или он упал.
- **Пинг всех серверов** одной кнопкой.
- **Правила по сайтам:**
  - «Всегда через VPN» и «Всегда напрямую»: свои белый и чёрный списки;
  - кнопки «Авто / Через VPN / Напрямую» для открытого сайта прямо в окне расширения.
- **Для РФ:**
  - российские сайты напрямую: банки, Госуслуги и маркетплейсы не ругаются на зарубежный IP;
  - заблокированное в РФ автоматически идёт через VPN по списку [itdoginfo/allow-domains](https://github.com/itdoginfo/allow-domains), примерно 1200 доменов, список обновляется сам.
- **Kill switch.** Если ядро упало или все серверы мертвы, сайты, которые должны идти через VPN, не откроются, а не уйдут мимо VPN с твоим реальным IP.
- **Защита от утечки IP через WebRTC.**
- **Локальная сеть всегда напрямую:** роутер, NAS, `localhost`, `*.local`.

## Как это устроено

```
Браузер ──(PAC: какой сайт куда)──► mihomo на 127.0.0.1:17890 ──► твой сервер (VLESS/Trojan/…)
   │                                  ▲
   └── расширение ──(REST API 127.0.0.1:19090, по secret)──┘  подписки, выбор сервера, пинг
```

Сам браузер не умеет VLESS и подобные протоколы: расширениям доступны только HTTP и SOCKS. Поэтому рядом работает маленькое ядро **mihomo** (бывший Clash.Meta). Оно открытое, скачивается с официального GitHub и слушает только `127.0.0.1`, так что снаружи компьютера к нему не подключиться.

## Установка

### 1. Ядро: одна команда в PowerShell

```powershell
irm https://raw.githubusercontent.com/DUFUSxD/lazeyka/main/install.ps1 | iex
```

Что сделает скрипт:
- скачает «Лазейку» в `%LOCALAPPDATA%\Lazeyka`;
- скачает mihomo с github.com/MetaCubeX/mihomo;
- создаст конфиг со случайным **secret** и скопирует secret в буфер обмена;
- запустит ядро в фоне и добавит его в автозагрузку Windows;
- откроет папку с расширением.

### 2. Расширение

1. Открой `chrome://extensions`. В Edge это `edge://extensions`, в Яндекс.Браузере `browser://extensions`.
2. Включи **«Режим разработчика»**.
3. Нажми **«Загрузить распакованное»** и выбери папку `%LOCALAPPDATA%\Lazeyka\extension`.
4. Закрепи значок расширения на панели (иконка-пазл → булавка).

### 3. Настройка

1. Нажми на значок «Лазейки» и открой **«Настройки»**.
2. **Secret:** вставь из буфера обмена. Если буфер уже перезаписан, secret лежит в `%LOCALAPPDATA%\Lazeyka\core\config.yaml`, строка `secret:`.
3. **Подписки:** ссылки по одной на строку.
4. Нажми **«Сохранить»**: появится список серверов.
5. Нажми **«ВКЛ»**.

## Сайты: что через VPN, что напрямую

Правила проверяются сверху вниз, срабатывает первое подходящее:

| # | Правило | Куда |
|---|---|---|
| 1 | Локальная сеть (`192.168.*`, `10.*`, `localhost`, `*.local`) | напрямую |
| 2 | Свои списки «Всегда через VPN» / «Всегда напрямую» (и кнопки для открытого сайта) | как указал |
| 3 | Заблокированное в РФ (если включено) | через VPN |
| 4 | Российские сайты (если включено) | напрямую |
| 5 | Всё остальное, настройка «Остальные сайты» | через VPN или напрямую |

- Домен покрывает и поддомены: `google.com` распространяется на `mail.google.com`.
- В своих списках побеждает самый точный домен. Например, `google.com` напрямую, а `gemini.google.com` через VPN: Gemini пойдёт через VPN, остальной Google напрямую.
- В списки можно вставлять что угодно: `https://www.youtube.com/watch?v=…`, `*.youtube.com`, `пример.рф`. Всё приводится к домену само.

### Готовые рецепты

| Хочу | «Остальные сайты» | РФ напрямую | Заблокированное через VPN |
|---|---|---|---|
| Как Browsec, но без проблем с банками | через VPN | ✅ | любое |
| Только заблокированное через VPN: быстрее всего, меньше трафика | напрямую | ✅ | ✅ |
| Только мои сайты через VPN | напрямую | любое | ❌ (и заполни «Всегда через VPN») |
| Всё через VPN без исключений | через VPN | ❌ | любое |

## Обновление

Запусти ту же команду, что и при установке:

```powershell
irm https://raw.githubusercontent.com/DUFUSxD/lazeyka/main/install.ps1 | iex
```

mihomo и secret сохранятся. После обновления нажми ⟳ на карточке «Лазейки» в `chrome://extensions`.

## Перенос на другой компьютер

1. Выполни на новом компьютере шаги «Установка» 1–3.
2. Подписки и списки сайтов скопируй из «Настроек» старого браузера.
3. Secret на каждом компьютере свой: бери тот, что выдал установщик на этом компьютере.

Что нужно от сети на новом месте:
- **Один раз доступ к GitHub**, чтобы скачать mihomo. Если GitHub там закрыт, скачай `mihomo-windows-amd64-compatible-*.zip` [со страницы релизов](https://github.com/MetaCubeX/mihomo/releases) где угодно и положи exe как `%LOCALAPPDATA%\Lazeyka\core\mihomo.exe`.
- **Ссылка на подписку должна открываться напрямую.** Её качает ядро без VPN, ведь до первой загрузки серверов ещё нет.
- **Доступ к самим серверам.**

## Удаление

1. Удали расширение в `chrome://extensions`.
2. Выполни в PowerShell:

```powershell
Get-Process mihomo -ErrorAction SilentlyContinue | Where-Object Path -like "$env:LOCALAPPDATA\Lazeyka\*" | Stop-Process -Force
Remove-ItemProperty HKCU:\Software\Microsoft\Windows\CurrentVersion\Run LazeykaMihomo -ErrorAction SilentlyContinue
Remove-Item "$env:LOCALAPPDATA\Lazeyka" -Recurse -Force
```

## Проблемы

| Сообщение / симптом | Что делать |
|---|---|
| «mihomo не запущен» | Запусти в PowerShell `powershell -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\Lazeyka\core\mihomo.ps1"`. Если ошибка, посмотри её текст там же. |
| «mihomo 401» | Неверный secret. Скопируй его из `core\config.yaml`. |
| «Нет серверов» | Подписка не скачалась: проверь, открывается ли ссылка в браузере **без** VPN. Нажми «Обновить подписки и списки». |
| Все сайты через VPN не открываются, пинг везде ✕ | Серверы недоступны из этой сети, или подписка истекла. Выбери другой сервер или «⚡ Авто». |
| «Прокси занят другим расширением» | Отключи Browsec, ZeroOmega и подобные: прокси в браузере может держать только одно расширение. |
| «Прокси заблокирован политикой браузера» | Рабочий компьютер: администратор запретил менять прокси. Тут ничего не сделать. |
| Порт 17890 или 19090 занят | Поменяй порты в `core\config.yaml` и в `extension\lib.js` (`PORT`, `CONTROLLER`), а также в `host_permissions` в `manifest.json`. |
| При запуске Edge/Chrome предлагает отключить «расширения в режиме разработчика» | Нажми «Оставить» или закрой предупреждение: так браузер ведёт себя со всеми расширениями не из магазина. |
| Звонки в браузере (Телемост, VK) хрипят | Сними галку «Защита от утечки IP через WebRTC». |

## Безопасность

- Ядро слушает только `127.0.0.1`. API закрыт случайным secret: без него сайты из интернета не смогут перенастроить прокси.
- Подписки и списки сайтов хранятся только в локальном хранилище браузера. В облако и в репозиторий ничего не уходит.
- Список заблокированного качается с `raw.githubusercontent.com/itdoginfo/allow-domains`. Если ответ битый или подозрительно короткий, остаётся прежний список.

## Разработка

```powershell
node test.mjs                    # конфиг mihomo, разбор доменов, маршрутизация (исполняется настоящий PAC)
node e2e.mjs path\to\mihomo.exe  # логика расширения против настоящего mihomo на фейковой подписке
```

Структура:
- `extension/`: расширение (Manifest V3, без сборки и зависимостей);
- `core/mihomo.ps1`: установка и запуск ядра;
- `install.ps1`: установщик одной командой.
